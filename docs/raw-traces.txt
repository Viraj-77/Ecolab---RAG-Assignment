=== WORKFLOW TEST: Add + assign in one execute() call ===

>> tool: execute
>> code:
new_tech = radar.add_technology(
    id='test-smoke-tech',
    label='Smoke Test Technology',
    quadrant=2,
    link='https://example.com/smoke'
)
radar.assign('llm-capability-office', new_tech.id, 1, 1)
radar.commit('test: smoke test add and assign')
result = radar.get_assignment('llm-capability-office', new_tech.id)

>> stderr (server-side log line emitted by RadarProxy.commit):
[commit] test: smoke test add and assign

>> response:
{"tech": "test-smoke-tech", "ring": 1, "moved": 1}

VERDICT: PASS — four operations (add_technology, assign, commit,
get_assignment) ran in a single execute() call. Single round-trip,
single tool invocation, single commit message. This is the multi-step
workflow win (one execute() vs four MCP round-trips in the N-tool
baseline).
